새 기능

    안드로이드 설치 방법

    1. 위의 안드로이드 앱 받기를 누르면 VoxelValley.apk가 내려받아져요.
    2. 다운로드 알림(또는 내 파일 › 다운로드)에서 파일을 눌러요.
    3. 처음이면 “출처를 알 수 없는 앱 설치 허용”을 켜고 설치를 눌러요.

    Play 스토어가 아닌 곳에서 받은 앱이라 Play 프로텍트가 확인 창을 띄울 수 있어요. “무시하고 설치”를 누르면 됩니다.

    아이폰 무료 설치 (홈 화면 앱)

    1. 위의 아이폰 · PC: 무료로 바로 플레이를 Safari에서 열어요. 카카오톡이면 오른쪽 아래 ⋯ → Safari로 열기.
    2. 아래쪽 공유 버튼(□↑) → 홈 화면에 추가 → 추가.
    3. 홈 화면에 생긴 Voxel Valley 아이콘을 누르면 주소창 없이 전체화면 앱처럼 실행돼요. 휴대폰은 가로로 들어 주세요.

    완전히 무료예요. 애플은 앱스토어·TestFlight(연 $99 개발자 계정 필요)를 거치지 않은 앱 파일 설치를 막고 있어서, 아이폰은 같은 게임을 웹 앱으로 드려요. 진행 상황(머니·무기)은 그 아이폰의 Safari에 저장돼요.

    모든 효과음·배경음은 코드로 직접 합성했고, 아이콘·블록 텍스처·UI도 직접 그려 만든 것이라 외부 저작물을 쓰지 않았어요.
